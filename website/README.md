# ARSIP QUEST Website

Website company profile untuk ARSIP QUEST: The Living Archive - Board Game Edukatif Sejarah Indonesia.

## Struktur File

- `index.html` - Halaman utama website
- `css/style.css` - Styling dengan desain semi modern vintage
- `js/script.js` - JavaScript untuk interaktivitas dan animasi
- `images/` - Folder untuk gambar produk

## Palet Warna

- Cream parchment: #F8F1E4
- Dark Brown: #4B2E1E
- Gold: #C89B3C
- Navy: #142235
- Accent Red: #B53A2D

## Cara Menjalankan

Buka `index.html` di browser web modern. Website sudah responsif dan dioptimalkan untuk desktop dan mobile.

## Fitur

- Fully responsive design
- Smooth scrolling navigation
- Hover animations
- Parallax background effect
- Modern typography dengan font Cinzel dan Poppins
- Semi modern vintage aesthetic dengan elemen arsip
